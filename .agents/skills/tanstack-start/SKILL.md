# Tanstack Start in goblin

The web app is a thin browser projection over the resident runtime. TanStack Start owns routing and build integration.

- Verify pinned Start/Router/Vite APIs in installed declarations and current docs; no parallel custom React Router application.
- Keep browser zones free of runtime internals, Worker bindings, Bun and Node imports. Server/tooling exceptions must be explicit in the workspace graph.
- Cross-runtime contracts come from packages/contracts; UI primitives come from packages/ui. Do not add hypothetical reuse packages.
- Generated shadcn components remain editable and locally owned; follow monorepo aliases/components.json and token conventions.
- Support text/tool/progress display, submit/follow-up, stop, snapshot reconnect, and a sandboxed App surface without another agent state machine.
- Keep the composer as one native textarea. Its `/` and `@` picker produces stable-identity chips, preserves unselected
  prose, supports keyboard and IME behavior, and is shared by full, draft and compact inline composers. Local commands
  stay local; server failures preserve the draft and identify the chip.
- Tool payloads use the local `JsonView` and `ToolPayload` primitives. Select MCP structured output from existing redacted details, retain supplementary content and exact Raw text, and keep JSON branches and large child lists bounded. Markdown output (`lib/markdown.ts`) renders through `ToolMarkdown` as untrusted text: no images, only absolute http(s)/mailto links, raw HTML as text. Rendering grants nothing and fetches no remote content.
- Every conversation, draft and App is one tab-less pane (ADR 0019): the pure store in `lib/workspace.ts` owns the
  layout and drives Trellis 0.3.0 (desktop, after hydration, controlled) or the narrow snapping strip; items render
  once into stable portal hosts. Routes carry only the focused conversation or App (`/c/$conversationId`,
  `/a/$appId`); never add search-param panel state. `src/routeTree.gen.ts` is generated by the build. Stored layouts are bounded, versioned, per owner/device and grant nothing.
- Validate the built artifact and real browser behavior. Local route rendering is not Cloudflare deployment proof.

Before changing an API call, read the current [documentation](https://tanstack.com/start/latest) and the installed package's declarations; the
lockfile pins the versions. [Architecture](../../../docs/architecture.md) describes how goblin uses it today.

Inner loop: `bun run check:files <paths>`. Before calling it done: `heavy bun run check`. This skill does not by
itself authorize model spend, external messages, deployment or production changes.

- Home (ADR 0025) belongs only to Main and uses the existing MessageScroller/dock. Fixed geometry, shared order/size, page > Home > inline slots and one canonical App frame are invariants. Owner edit mode is device-local; gestures preserve native scrolling, carry release velocity, have keyboard equivalents and respect reduced motion. Ask for a tile, refreshed starters and the edit placeholder fill and focus the composer without sending; empty Home renders no stray zero. MCP App pins are owner-only; Home frames and grant cards stay within fixed tile bounds after motion settles. The installed iPhone cold-launch check belongs to the owner.
