# Tanstack Start in goblin

The web app is a thin browser projection over the resident runtime. TanStack Start owns routing and build integration.

- Verify pinned Start/Router/Vite APIs in installed declarations and current docs; no parallel custom React Router application.
- Keep browser zones free of runtime internals, Worker bindings, Bun and Node imports. Server/tooling exceptions must be explicit in the workspace graph.
- Cross-runtime contracts come from packages/contracts; UI primitives come from packages/ui. Do not add hypothetical reuse packages.
- Generated shadcn components remain editable and locally owned; follow monorepo aliases/components.json and token conventions.
- Support text/tool/progress display, submit/follow-up, stop, snapshot reconnect, and a sandboxed App surface without another agent state machine.
- Keep the composer as one native textarea. Its `/` and `@` picker produces stable-identity chips, preserves unselected
  prose, supports keyboard and IME behavior, and is shared by full, draft and compact inline composers. Local commands
  stay local; server failures preserve the draft and identify the chip.
- Tool payloads use the local `JsonView` and `ToolPayload` primitives. Select MCP structured output from existing redacted details, retain supplementary content and exact Raw text, and keep JSON branches and large child lists bounded. Markdown output (`lib/markdown.ts`) renders through `ToolMarkdown` as untrusted text: no images, only absolute http(s)/mailto links, raw HTML as text. Rendering grants nothing and fetches no remote content.
- Mermaid fences use the kit's inert preview and read-only native-dialog explorer (ADR 0023). Keep untrusted inline
  SVG behind `diagram-svg.ts`: scoped CSS, unique marker IDs, no active elements or external references. Verify
  gestures, node selection, focus return and frame confinement with `apps/web/test/ui-diagram.ts`.
- The app is a Slack-style shell (ADR 0036, `components/shell`): rail, sidebar of Topic channels, the channel, and a
  thread panel beside it. Routes carry where you are: `/c/$chatId` with search `{ thread?, stack?, reply? }` parsed by
  `lib/panel.ts` (ids stay numbers in the URL), `/a/$appId` for an App's page (search `{ focus? }` for a server's own
  App, ADR 0053), and the rail pages. The sidebar's Pinned section reads the owner's synced pins (`sidebar/hooks.ts`). A thread's own
  `/c/<id>` redirects to its channel with the panel open. Apps and composers reach the shell only through
  `lib/navigation.ts`. `src/routeTree.gen.ts` is generated by the build (and the dev server).
- Server data follows the data-layer rule in [apps/web/AGENTS.md](../../../apps/web/AGENTS.md#data-layer): typed
  clients, per-feature `queries.ts` (factories and keys) and `hooks.ts`, mutations that reach the cache through
  `context.client`, loaders that prime ahead of `OwnerGate` without deciding anything, `useSuspenseQuery` inside a
  `QueryBoundary` within `OwnerGate`, and the workspace feed kept in the same cache by `lib/workspace/`
  ([docs/agents/ui.md](../../../docs/agents/ui.md)). `getRouter` (`router.tsx`) makes one `QueryClient`
  per router, never at module scope, and puts it in the router context; its unauthenticated callback clears the cache
  and goes to `/login`. The router's default error component is `ReportedRouteError`, which shows the failure with its
  reference and reports a defect to `/api/client-errors`; `routes/__root.tsx` reports uncaught errors and rejections
  the same way (`lib/query/crash-report.ts`, content-free, ADR 0037).
- `/` is goblin's public landing for a visitor who is signed out (`components/landing`, built from `@goblin/ui`'s
  marketing parts, which Goblin Wallet's front door shares); its `beforeLoad` sends a signed-in owner to their channel
  (the session cookie on the server, the cached session in the browser, never a network wait). The root draws it
  without the shell. `heavy bun apps/web/test/ui-landing.ts` checks it in Chromium.
- "Only visible to you" rows (`components/shell/ephemeral-slot.tsx`) are owner-only, never transcript entries or
  sends. Decision proposals fill them (`decisions/hooks.ts`, `decisions/rows.ts`, ADR 0031): a choice posts its label
  to `POST /api/decisions/:id`, and a confirmed thread suggestion opens an empty thread draft through `Navigation`.
  The rows are a report highlight (Useful), a thread suggestion (New thread) and earlier work (Use), each with
  Dismiss.
- Validate the built artifact and real browser behavior. Local route rendering is not Cloudflare deployment proof.

Before changing an API call, read the current [documentation](https://tanstack.com/start/latest) and the installed package's declarations; the
lockfile pins the versions. [Architecture](../../../docs/architecture.md) describes how goblin uses it today.

Inner loop: `bun run check:files <paths>`. Before calling it done: `heavy bun run check`. This skill does not by
itself authorize model spend, external messages, deployment or production changes.

- Main renders the transcript and composer. The Home dashboard is deferred (ADR 0025); no tile UI, pin controls or Home scroll anchors remain. Apps follow page > inline placement. Retain persisted Home data and runtime authority boundaries for a later iteration.
